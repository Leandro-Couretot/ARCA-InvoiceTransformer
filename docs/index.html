Conectar Google Sheets

El dashboard necesita una URL de Google Apps Script para obtener datos automáticamente de la hoja gastos_unificados.

  1. Abrí el spreadsheet → Extensiones → Apps Script
  2. Reemplazá el contenido con el código de gas/Code.gs
  3. Implementar → Nueva implementación → Aplicación web
  4. Ejecutar como: Yo · Acceso: Cualquiera
  5. Copiá la URL de implementación y pegala acá
